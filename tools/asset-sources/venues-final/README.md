# Venue backgrounds, final pass (Wikimedia Commons)

One folder per team slug: `day.jpg` (and `night.jpg` where a good one exists), at most 2400 px wide, plus `SOURCES.json` with the Commons page, original URL, downloaded size, license, author, credit line, year, whether it is an aerial, and a one-line note on the viewpoint and the pixel rows where the field sits. Teams with nothing usable have an empty `files` list and their closest misses with the reason.

Preference order: high oblique drone/aerial view into the bowl, then an elevated upper-deck or press-box view with the field filling much of the frame. Licenses limited to CC0, public domain, CC BY and CC BY-SA. Researched 2026-11-27.

**Counts:** 23 teams; 29 images. Day+night 9, day only 11, night only 0, none 3. Aerial (drone) day photo for 7 teams.

- Several picks are older than the stadium's latest renovation; each note says which part changed and whether it is in frame.
