# Venue interior photos, set 2 (Wikimedia Commons)

Elevated interior stadium photos for scoreboard backgrounds, one folder per team slug. Each folder has `SOURCES.json` (license, author, credit line, where the field sits in the frame) and `day.jpg` / `night.jpg` at 2400 px wide (or the original width if narrower). Files marked LAST RESORT in their note are high oblique aerials, not stands views.

Researched 2026-11-25. Licenses limited to CC0, public domain, CC BY and CC BY-SA.

**Counts:** 24 venues; day+night 6, day only 16, night only 1, none 1.
