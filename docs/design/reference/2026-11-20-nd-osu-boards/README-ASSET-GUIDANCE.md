# Suite Home + Game visual handoff assets — Notre Dame vs Ohio State

These are visual direction boards for the Stage 2 Home and Game redesign.
They are reference boards, not production UI code or individual production-ready
helmet/stadium files. Do not trace them into SVGs or embed the boards as app UI.

Use them to understand the intended finished experience, lifecycle coverage,
responsive compositions, and photographic asset direction. Create or source
individual production assets where needed, and place optimized assets in the
repository's established public/static asset location.

Important:
- Treat text, scores, dates, player details, and small labels in mockups as illustrative.
- Use actual TeamOS data and approved product logic.
- Notre Dame and Ohio State are the proof-of-concept teams.
- Preserve team identity authenticity; never recolor generic helmets to fake team assets.
- Preserve creative autonomy: the boards communicate intent, not pixel-perfect constraints.
