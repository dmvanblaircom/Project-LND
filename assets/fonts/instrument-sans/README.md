# Instrument Sans

SIL Open Font License; see `OFL.txt`.
Source: [Google Fonts / Instrument Sans](https://github.com/google/fonts/tree/main/ofl/instrumentsans), `InstrumentSans[wdth,wght].ttf`, downloaded October 4, 2026.

Both files retain the native variable weight axis (400–700). `instrument-sans.woff2` pins width to 100; `instrument-display.woff2` pins it to 80. There is no CSS transform or synthetic condensation. CSS disables synthetic weight/style; Georgia retains the editorial role by David's October 4 decision.

Built with FontTools 4.66.1 and Brotli 1.2.0: instantiate only the `wdth` axis, subset Unicode U+0000–024F, U+1E00–1EFF, U+2000–206F, plus U+20AC, U+2122, U+2191, U+2193, U+2212, U+FEFF, U+FFFD, then save with `flavor='woff2'`. The two files total approximately 61 KB. Both are precached with the common app shell.
